# 地图工作区

地图页作为地理数据工作台使用，界面组件采用 shadcn-vue。

## 数据工作流

1. 在「导入」中选择或拖放 GeoJSON、KML、WKT 文件，并确认源坐标系。
2. 在「图层」中重命名、排序、调整显隐与不透明度，切换街道或卫星底图。
3. 在「属性」中选择业务图层，按名称、编号、任意属性值或几何类型筛选；列表每页 20 个要素，可查看属性、定位、选择并导出。
4. 在「编辑」中调整节点，撤销或恢复本次初始状态；修改立即同步工作区数据，结束编辑后可导出整个图层。
5. 在「热力」中选择实际点位图层，按密度或数值属性生成热力图，调整影响半径、模糊程度和不透明度。修改源数据后点击更新。
6. 在「分组」中选择至少两个矢量图层并命名，统一调整显示与不透明度；解除分组保留数据与子层偏好。当前支持一个分组。
7. 在「服务」中添加 WMS 或 WMTS 资源，管理服务显示与不透明度，查看连接状态。
8. 使用底部工具栏定位经纬度、保存视图、截图或全屏。

绘制、测量、要素选择和几何编辑互斥。绘制、导入、标注和底图偏好在页面切换时保留；热力图、分组、服务配置属于当前地图会话，离开页面时释放。刷新后数据保留范围沿用已有工作区机制。

## 地图服务

WMS 需提供服务 URL、图层名称、版本、投影和图像格式。

WMTS 还需矩阵集、样式、网格 JSON：origin 为两个有限数值，resolutions 为正数数组，matrixIds 为等长字符串数组；可提供 tileSize 和各层矩阵宽高 sizes。标准 Web Mercator 网格按钮提供 256px 瓦片、0–19 级数字矩阵标识，需按实际服务元数据调整。当前不自动解析 GetCapabilities。

服务连通状态反映瓦片加载结果。真实内容和位置需使用有效服务配置核对。
